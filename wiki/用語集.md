| ことば | 意味 |
|---|---|
| LaTeX（ラテフ・レイテック） | 文章と組み方の指示をテキストで書き、PDF に組み上げる仕組み。数式に強い |
| TeX Live | LaTeX を使うためのソフト一式。毎年新しい版が出る（このリポジトリは 2026 年版が前提） |
| MacTeX | Mac 向けの TeX Live |
| LuaLaTeX | LaTeX の処理系の1つ。日本語と、パソコンに入っているフォントを使いやすい。このリポジトリはこれを使う |
| latexmk | LaTeX のビルド（PDF を作る作業）を、必要な回数だけ自動でくり返す道具 |
| ビルド | `.tex` ファイルから PDF を作ること |
| Beamer | LaTeX でスライドを作る仕組み |
| TikZ | LaTeX で図を描く仕組み。このリポジトリの図はすべてこれで描いている |
| `.log` ファイル | ビルドの記録。エラーの詳細が出る |
| Overfull | 文字や図が枠からはみ出していることを知らせる警告 |
| AMC（Auto Multiple Choice） | マークシートの作成・スキャン・自動採点をする無料のソフト |
| WSL2 | Windows の中で Linux を動かす仕組み。Windows で AMC を使うときに使う |
| リポジトリ | ファイル一式と、その変更の履歴をまとめたもの |
| Git | ファイルの変更の履歴を残す道具 |
| GitHub | リポジトリを置いて共有する Web サービス |
| テンプレートリポジトリ | 「Use this template」で、自分用のコピーを作れるリポジトリ |
| Markdown | `#` で見出し、`-` で箇条書きのように、簡単な記号で書く文章の形式。`syllabus.md`・`lesson_plan.md` はこれで書く |
| `syllabus.md` | 科目全体の設計（目標・各回のテーマ・評価・授業の型・教材の作り方） |
| `lesson_plan.md` | 1回分の授業計画（到達目標・授業の流れ・教材ごとの設計） |
| スキル | 生成 AI に渡す作業手順書。`.agents/skills/` にある |
| Agent Skills | スキルを複数の AI ツールで共通に使うための書き方の決まり |
| `AGENTS.md` | このリポジトリで作業する AI への共通の指示 |

| MIT ライセンス | 自由に使い・改変できるソフトウェアのライセンス |
