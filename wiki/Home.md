# lecture-factory-starter へようこそ

**授業のスライド・配布資料・ワークシート・選択式問題（マークシート）を、LaTeX でまとめて作るためのテンプレートとサンプル教材**です。
大学の授業で実際に使っている教材づくりの仕組みから、どの大学・どの科目でも使える部分だけを取り出しました。Windows でも Mac でも、同じ手順で使えます。

## こんな方に

- スライドとワークシート、小テストを、**同じ見た目・同じ手順**で毎回作りたい
- 数式や図の多い授業の資料を、きれいに、繰り返し直しながら作りたい
- 生成 AI（Claude Code・Codex など）に、シラバスから授業計画・教材の下書きまで手伝ってもらいたい
- PowerPoint などで作ってきた資料を、整理し直したい

LaTeX を使ったことがなくても始められます。最初は、サンプル教材をビルドして PDF ができるところまでを目標にしてください。

## 1つのソースから、できるもの

| できるもの | 説明 |
|---|---|
| 投影用スライド | 16:9。1枚1メッセージ＋図の型 |
| 配布用ハンドアウト | スライドを A4 横1ページに4枚。スライドを直せば自動で追従 |
| ワークシート（学生用・解答版） | 同じソースから2種類。記入欄の大きさは両方で同じ |
| 選択式の確認問題 | マークシート形式。紙で配るだけなら TeX だけで作れ、スキャンして自動採点もできる（任意） |
