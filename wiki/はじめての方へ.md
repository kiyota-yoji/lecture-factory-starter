サンプル教材をビルドして、**最初の PDF を作るまで**の流れです。くわしい手順は OS ごとの手順書にあります。

所要時間の目安：TeX Live のインストールに1〜2時間（ほとんど待ち時間）、それ以外は15分ほどです。

## 1. TeX Live 2026 を入れる

LaTeX の文書を PDF にするためのソフト一式です。無料です。

| OS | 入れるもの | 手順書 |
|---|---|---|
| Windows 10 / 11 | TeX Live 2026（公式インストーラ） | [SETUP_WINDOWS.md](https://github.com/kiyota-yoji/lecture-factory-starter/blob/HEAD/docs/SETUP_WINDOWS.md) |
| Mac | MacTeX 2026 | [SETUP_MAC.md](https://github.com/kiyota-yoji/lecture-factory-starter/blob/HEAD/docs/SETUP_MAC.md) |

- 古い TeX（W32TeX など）が入っている場合は、手順書の「確認する」で、新しい方が使われていることを確かめてください。
- エディタは [VS Code](https://code.visualstudio.com/) ＋ 拡張機能「LaTeX Workshop」がおすすめです（任意）。設定はリポジトリに入っています。

## 2. このリポジトリを手元に置く

次のどちらかです。

- **自分の教材を作っていくなら**：GitHub のページの「**Use this template**」で、自分のアカウントにコピーを作ります（GitHub のアカウントが必要）。
- **まず試すだけなら**：「**Code → Download ZIP**」でダウンロードして展開します。

置き場所は `C:\work\lecture-factory-starter` のような、**半角英数字だけのフォルダ**にしてください。日本語や空白を含むフォルダ、OneDrive などの同期フォルダは避けます。

## 3. ビルドする

ターミナル（Windows は PowerShell、Mac は「ターミナル」）で、リポジトリのフォルダに移動してから実行します。

```bash
latexmk -cd courses/basic_math/07/slides.tex
```

`courses/basic_math/07/slides.pdf` ができれば成功です。初回は、フォントの準備に数分かかることがあります（止まったように見えても待ってください）。

すべてのサンプルをまとめてビルドするには：

```bash
texlua tools/build_all.lua
```

VS Code を使う場合は、フォルダを開いて `.tex` ファイルを保存するだけで PDF ができます。
