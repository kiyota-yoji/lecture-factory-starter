PowerPoint・Google スライド・Keynote・PDF などで作ってきた授業資料を、このリポジトリの形（授業計画と LaTeX の教材）に作り直す流れです。
置き場所と扱いの決まりは [SOURCE_MATERIALS.md](https://github.com/kiyota-yoji/lecture-factory-starter/blob/HEAD/docs/SOURCE_MATERIALS.md) にあります。

## 気をつけること

既存の資料には、**そのまま公開・再配布してはいけないもの**が混ざっていることがよくあります。

- サービスや企業の**ロゴ**
- アプリや Web サービスの**画面写真**
- Web から持ってきた**写真・イラスト**、他の人が作った**図表**
- 学生の名前・提出物が写った画面
- 締切の日付・教室などの、その年度だけの情報

作り直すときは、これらを**使わずに**、文字や自分で描いた図に置き換えます。

## 流れ

1. **原本を置く**：回のフォルダの `source/original/` にコピーします。このフォルダは Git に入らない設定になっています（公開されません）。
2. **点検する**：1ページずつ、上のようなものがないかを見て、`source/SOURCES.md` に記録します。年号・数値は、発表元の資料などで確かめ直します。
3. **公開用の写しを作る（任意）**：原本からロゴなどを消した PDF を作り、`source/<略号NN>_public.pdf` として残します。
4. **授業計画を書き起こす**：内容と順番は原本のまま `lesson_plan.md` に書き、原本のページと新しいスライドの対応表をつけます。
5. **教材を作る**：授業計画に沿ってスライドなどを作ります。ロゴは文字に、画面写真は自分で描いた模式図に置き換えます。

生成 AI に頼む場合は、「この PDF をもとに、`my_course` の第05回を作り直して」のように頼むと、この流れで進みます（スキル `existing-materials`）。

## 学生の情報が写っている資料

提出物・名簿・成績・座席表など、学生の情報を含むものは、**リポジトリのフォルダの中に置かないでください**（`source/original/` にも置きません）。同期ソフトや設定の誤りで外に出るおそれがあります。

## 見本

[courses/ai_business/08/](https://github.com/kiyota-yoji/lecture-factory-starter/tree/HEAD/courses/ai_business/08) は、Google スライドの資料（35ページ）から作り直した例です。

- `source/SOURCES.md`：ページごとの点検の結果、確かめた事実（原本の年号の誤りを直したことなど）
- `source/aib08_public.pdf`：ロゴ・画面写真を消した原本の写し
- `lesson_plan.md`：書き起こした授業計画と、原本との対応表
