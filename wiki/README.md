# wiki/ — GitHub Wiki の原稿

このフォルダは、GitHub の Wiki（利用者向けの案内ページ）の**原稿**です。Wiki はリポジトリとは別に管理されるため、原稿をここに置いてリポジトリと一緒に見直し、`tools/publish_wiki.sh` で Wiki に写します。

- **Wiki を直すときは、このフォルダを編集します。** GitHub の Wiki の画面で直接編集すると、次に写したときに上書きされます。
- このファイル（`README.md`）は Wiki には写しません。
- ページ名＝ファイル名です（`はじめての方へ.md` → ページ「はじめての方へ」）。`Home.md` が表紙、`_Sidebar.md` が横の目次、`_Footer.md` が各ページの下に出る文です。
- Wiki のページどうしのリンクは `[表示](ページ名)`、リポジトリのファイルへのリンクは `https://github.com/kiyota-yoji/lecture-factory-starter/blob/main/<パス>` の形の絶対 URL で書きます。
- 書き方の方針：Wiki は**入口**（はじめての方へ・流れ・よくある質問）です。手順の細部は `docs/` にあり、Wiki からはリンクで案内します（同じことを2か所に書かない）。
- リンク切れは `texlua tools/check_wiki.lua` で確かめられます（自動ビルドでも確かめます）。

## Wiki に写す（公開後、メンテナーが行う）

1. GitHub のリポジトリの「Wiki」タブで、最初のページを1度だけ手で作る（Wiki の保存場所を作るため。中身は何でもよい）。
2. リポジトリのルートで次を実行する（`git` が必要）。

```bash
tools/publish_wiki.sh
```

このテンプレートから自分のリポジトリを作った場合、このフォルダは元のプロジェクトの案内です。不要なら削除して構いません。
