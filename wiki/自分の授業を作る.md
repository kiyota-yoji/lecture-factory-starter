生成 AI を使わずに、自分の科目の教材を作る流れです。生成 AI と作る場合は [生成AIと使う](生成AIと使う) を見てください。
くわしい書き方は [AUTHORING_GUIDE.md](https://github.com/kiyota-yoji/lecture-factory-starter/blob/main/docs/AUTHORING_GUIDE.md) にあります。

## 1. 科目のフォルダを作る

`courses/` の下に、科目のフォルダ（半角英数字）と、回のフォルダ（2桁の番号）を作ります。

```text
courses/
└─ my_course/
   ├─ syllabus.md
   └─ 01/
      ├─ lesson_plan.md
      ├─ slides.tex       投影用スライド
      ├─ handout.tex      配布用（スライドを A4 横に4枚）
      ├─ worksheet.tex    ワークシート
      ├─ worksheet_answers.tex  ワークシートの解答版
      ├─ amc/exercise.tex 選択式の確認問題
      └─ figures/         図
```

使う教材だけ作れば構いません。たとえば、スライドだけの授業なら `slides.tex` と `handout.tex` だけで十分です。

## 2. シラバスと授業計画を書く（おすすめ）

- `templates/syllabus.md` を `courses/my_course/syllabus.md` にコピーして埋めます。公式シラバスの内容に加え、「1回の授業の型」と「教材の作り方」を書いておくと、毎回の教材がそろいます。
- `templates/lesson_plan.md` を各回のフォルダにコピーして、到達目標と授業の流れを書きます。

なくても教材は作れますが、生成 AI に手伝ってもらうときは必須です。

## 3. 雛形をコピーして書く

`templates/slides/`・`templates/worksheet/` の中のファイルと、`templates/amc/` フォルダを、回のフォルダにコピーします。

- **`slides.tex`**：1枚に1つのメッセージと、大きな図。説明の文章は詰め込まず、配布資料や口頭で補います。
- **`handout.tex`**・**`worksheet_answers.tex`**：本体を読み込むだけのファイルです。**中身は書き換えません。**
- **`worksheet.tex`**：問題ごとに記入欄の高さを指定します。解答も同じファイルに書くと、解答版にだけ赤字で出ます。
- **`amc/exercise.tex`**：1行目の `%%AMC:latex_engine=lualatex` は消さないでください。
- **図**は TikZ で描いて `figures/` に置くのがおすすめです。教科書の図や Web の画像は使わないでください（[ライセンスと著作権](ライセンスと著作権)）。

迷ったら、サンプル教材（`courses/basic_math/07/` など）を開いて、同じ書き方をまねてください。

## 4. ビルドして確かめる

```bash
texlua tools/build_all.lua courses/my_course/01
```

- すべて `OK` になれば成功です。エラーは [困ったとき](困ったとき) へ。
- PDF を開いて、文字のはみ出し・図の重なりがないかを見ます。`.log` ファイルに `Overfull` と出ていたら、どこかがはみ出しています。
- 解答・正解は、必ず自分で検算してください。

## 5. 印刷・配布する

| 用途 | ファイル |
|---|---|
| 投影 | `slides.pdf` |
| 配布資料 | `handout.pdf`（A4 横・4枚ずつ） |
| ワークシート | `worksheet.pdf`（学生用）・`worksheet_answers.pdf`（解答版） |
| 確認問題 | `amc/exercise.pdf` |

スライドの PDF を Adobe Acrobat から印刷するとエラーになることがあります。対処は [TROUBLESHOOTING.md](https://github.com/kiyota-yoji/lecture-factory-starter/blob/main/docs/TROUBLESHOOTING.md) の「見た目・印刷」にあります。
