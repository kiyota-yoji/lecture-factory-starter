エラーの対処は、エラーメッセージごとに [TROUBLESHOOTING.md](https://github.com/kiyota-yoji/lecture-factory-starter/blob/HEAD/docs/TROUBLESHOOTING.md) にまとめています。**エラーメッセージの一部で、ページ内を検索してください。**

## まず確かめること

1. **エラーの本体を見る**：ビルドした `.tex` と同じフォルダにできる `.log` ファイルの、`!` で始まる行がエラーの本体です。
2. **TeX Live 2026 が使われているか**：`lualatex --version` の1行目に `TeX Live 2026` と出るか。古い TeX が先に使われていることがよくあります。
3. **フォルダの場所**：日本語・空白を含むフォルダ、OneDrive などの同期フォルダの中では失敗しやすくなります。`C:\work\…` のような場所に移してください。
4. **途中のファイルを消してやり直す**：`texlua tools/build_all.lua --clean` のあと、もう一度ビルドします。

## よくある症状

| 症状 | 見るところ |
|---|---|
| `lualatex` や `latexmk` が「見つからない」「認識されない」 | TROUBLESHOOTING「コマンドが見つからない」。ターミナルを開き直す |
| Windows 11 で TeX Live のインストーラが「スマート アプリ コントロール」に止められる | TROUBLESHOOTING「スマート アプリ コントロールでインストーラが止められる」 |
| 初回のビルドが止まったように見える | フォントの準備中です。数分待ってください |
| `lfs-slides.sty` などが見つからない | リポジトリのルートで `latexmk -cd <ファイル>` を実行する。VS Code はフォルダごと開く |
| `BIZ UDPGothic` が見つからない（Mac） | フォントを入れるか、既定の原ノ味に戻す |
| `Overfull \vbox` と出る | スライドの中身がはみ出しています。図や文字を小さく・短くする |
| PDF を Acrobat から印刷できない | TROUBLESHOOTING「スライドの PDF を Adobe Acrobat から印刷するとエラーになる」 |
| AMC の画面が英語・□ になる、起動時に通知のダイアログが出る（WSL） | TROUBLESHOOTING「AMC」 |
| マークシートが読み取れない | TROUBLESHOOTING「AMC」 |

## 質問するとき

公開後は、GitHub の [Issues](https://github.com/kiyota-yoji/lecture-factory-starter/issues) で質問・不具合の報告を受け付けます。次を書いてもらえると、早く原因が分かります。

- OS（Windows 11、macOS 26 など）
- `lualatex --version` の1行目
- 実行したコマンド
- `.log` の `!` で始まる行と、その前後の数行

**学生の名前・成績などが写った画面やファイルは、貼らないでください。** Issues は誰でも読めます。
