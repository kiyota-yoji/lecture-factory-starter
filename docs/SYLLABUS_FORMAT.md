# syllabus.md の標準フォーマット

`syllabus.md` は、1科目1学期分の授業の**設計の土台**です。科目のフォルダの直下に1つ置きます（`courses/<科目ID>/syllabus.md`）。

- 大学の公式シラバス（Web・PDF）の内容を写したうえで、公式シラバスには書かれない「**どう実施するか**」「**教材をどう作るか**」を書き足します。
- 各回の授業計画（[`lesson_plan.md`](LESSON_PLAN_FORMAT.md)）は、この文書から作ります。内容が食い違ったときは `syllabus.md` を正とします。
- 作り方の手順は [WORKFLOW.md](WORKFLOW.md)、白紙の雛形は [`templates/syllabus.md`](../templates/syllabus.md) です。AI エージェント（Claude Code・Codex・Antigravity など）では `syllabus-markdown` スキルで作れます（[WORKFLOW.md](WORKFLOW.md)）。
- 記入例：[`courses/basic_math/syllabus.md`](../courses/basic_math/syllabus.md)、[`courses/ai_business/syllabus.md`](../courses/ai_business/syllabus.md)

---

## 1. 全体の形

```markdown
---
（front matter：YAML）
---

# コース概要
# 達成目標
# 対象学生
# 前提知識
# 授業計画
# 評価方法
# 授業の実施要件
# 教材の作り方
# 使用教材
# 公式シラバスとの差異
# 備考
```

- 見出しの名前と順番はこのとおりにします（スキルや人が探しやすくするため）。使わない任意の節は、見出しごと省略して構いません。
- `#` は主要な節、`##` は回や下位の区分、`###` は最小限にします。箇条書きは `-`、入れ子は1段までにします。
- 数式は LaTeX（`$...$`）で書けます。

## 2. front matter

| キー | 必須 | 内容 | 例 |
|---|---|---|---|
| `course_id` | ◎ | 科目 ID。フォルダ名と同じ半角英数字・`_` | `basic_math` |
| `course_name` | ◎ | 科目名 | `基礎数学` |
| `academic_year` | ◎ | 年度 | `2026` |
| `term` | ◎ | 学期（自由記述） | `春学期`、`後期`、`通年` |
| `total_lessons` | ◎ | 授業回数 | `14` |
| `duration_minutes` | ◎ | 1回の時間（分） | `100` |
| `target` | ○ | 対象学生 | `工学部1年` |
| `instructor` | ○ | 担当教員 | `山田 太郎` |
| `credits` | ○ | 単位数 | `2` |
| `delivery_mode` | ○ | 実施形態：`face_to_face`（対面）／`online`（同時双方向）／`on_demand`／`hybrid` | `face_to_face` |
| `lms` | ○ | 使う学習管理システム（自由記述） | `Moodle`、`Google Classroom`、`なし` |
| `source` | ○ | 公式シラバスの出典（URL かファイル名）と取得日 | `https://example.ac.jp/syllabus/123（2026-04-01 取得）` |

◎ 必須、○ 推奨。これ以外のキーを足しても構いません。

## 3. 各節の書き方

### `# コース概要`（必須）

- 公式シラバスの「授業の概要・目的」を**そのまま写し**、直後に出典を1行で書きます（採録した節ごとに、その節の直後に書きます。授業計画・評価方法なども同じ）。
  > （上記は公式シラバス（2026-04-01 取得）の「授業の概要と目的」を採録したもの。）
- 自分の言葉の補足（科目の位置づけ、全体の構成など）は、採録部分と分けて書きます。

### `# 達成目標`（必須）

- 公式シラバスに到達目標があるときは、**原文どおり**（数も言い回しもそのまま）に写します。補足は「（補足）」と付けた別の箇条にします。
- 自分で書くときは、「〜できる」の形の箇条書きで5〜10項目を目安にします。
- 各回の到達目標（`lesson_plan.md`）は、ここに書いた目標のどれかを具体化したものにします。

### `# 対象学生`（必須）

人数の規模、学年・学部、予備知識のばらつき、苦手意識の傾向などを書きます。説明の水準を決める根拠になります。

### `# 前提知識`（推奨）

どこまで既知として扱うか、扱わないかを書きます。

### `# 授業計画`（必須）

1回につき1つの見出し `## 第NN回: タイトル` を立てます（`NN` は2桁）。

```markdown
## 第07回: 微分法の基礎
- 平均変化率と瞬間変化率
- 微分の定義（導関数）
- 基本的な関数の微分、接線
- 演習: 定義に従った微分係数の計算
- 事前学修: 第03回の指数法則を見直す（1時間）／事後学修: ワークシートの解き直し（2時間）
```

- 最初の行は**扱う内容**です（自分で書くときは2〜4行）。公式シラバスの各回の記述があれば、欄ごとに1行で写します（例：`- 授業内容: …`、`- 事前学修: …`、`- 事後学修: …`）。
- 続けて、必要に応じて `演習:`、`事前学修:` / `事後学修:`、`教科書:`（章・ページで指す）を書きます。
- タイトルに `:` が含まれていても構いません（`第NN回: ` の後ろ全体がタイトルです）。
- 小テスト・試験・休講などの回も、見出しを立てて書きます。
- 節の冒頭に、全回に共通する事前・事後学修の説明や、回のまとまり（ブロック）の表を置いても構いません。

### `# 評価方法`（必須）

配点を `- 項目: NN%` で並べ（数字と `%` は半角）、必要に応じて下位の節で方針を書きます。学生の生成 AI の利用ポリシーは、この節の `## 生成 AI の利用ポリシー` に書きます（教材作りでの生成 AI の使い方は `# 教材の作り方` に書きます）。

```markdown
# 評価方法

- 授業内演習: 50%
- 小テスト: 20%
- 期末試験: 30%

## 授業内演習の方針
## 小テストの方針
## 生成 AI の利用ポリシー
```

### `# 授業の実施要件`（推奨）

公式シラバスには書かれにくい、**授業をどう運営するか**の決まりです。各回の授業計画と教材は、これを前提に作られます。

| 下位の節 | 書くこと |
|---|---|
| `## 実施形態` | 対面・オンライン・オンデマンドの別、教室の制約（人数・設備） |
| `## 1回の授業の型` | 毎回の基本の流れ（例：前回の振り返り10分 → 講義と演習を交互に → 確認問題5分 → まとめ） |
| `## 出席と提出` | 出席の取り方、提出物の出し方（紙・LMS）、締切の決め方 |
| `## フィードバック` | 演習・課題の結果をいつ、どう返すか |
| `## 配慮` | 配慮が必要な学生への対応の原則（個人の情報は書かない） |

### `# 教材の作り方`（推奨）

各回の教材（スライド・ワークシートなど）を**どの種類で、どう作るか**の決まりです。`lesson-materials` スキルはこの節に従って教材を作ります。

| 下位の節 | 書くこと |
|---|---|
| `## 毎回作る教材` | 毎回作るものの一覧（下の「教材の種類」の名前で）と、例外の回 |
| `## スライドの方針` | 枚数の目安、1枚あたりの情報量、図の使い方、和文フォント（原ノ味／BIZ UD） |
| `## ワークシートの方針` | 問題数、記入欄の大きさ、解答版の扱い |
| `## 確認問題の方針` | 問題数、選択肢の数、誤答選択肢の作り方、採点方法（手採点／AMC） |
| `## 表記の約束` | 用語・記号・ベクトルや行列の書き方など、科目の中でそろえること |
| `## 著作権と出典` | 教科書の問題文を転載しない（番号・ページで指す）、外部の図を使わない、出典の書き方 |
| `## 生成 AI の使い方` | 教材作りに生成 AI を使う範囲と、人が確かめる点 |

**教材の種類**（`lesson_plan.md` の `outputs` と共通の名前）

| 名前 | ファイル | 内容 |
|---|---|---|
| `slides` | `slides.tex` | 投影用スライド |
| `handout` | `handout.tex` | 配布用（スライドを A4 横に4枚） |
| `worksheet` | `worksheet.tex`・`worksheet_answers.tex` | ワークシート（学生用・解答版） |
| `exercise` | `amc/exercise.tex` | 選択式の確認問題 |
| `lecture_script` | `lecture_script.md` | 講義台本（話す内容の骨子） |

### `# 使用教材`（推奨）

教科書・参考書・参考サイトを `## 教科書` / `## 参考書` などに分けて書きます。教科書の問題を使う回は、授業計画に章・ページで書きます。

### `# 公式シラバスとの差異`（任意）

実際の運用が公式シラバスと違う点を、差異ごとに `##` を立てて記録します。公式シラバスの採録部分は書き換えません。

### `# 備考`（任意）

試験期間、予備日、公式シラバスにだけある項目（`## 公式シラバスのその他の項目`：題目・関連科目・履修条件・使用言語など）、未確定の事項（`## 未確定事項` にチェックリストで）などを書きます。

## 採録の例

公式シラバスが次のように書かれているとき（架空の例）：

```text
授業の到達目標：１．関数の性質を理解する。２．基本的な微分の計算をする。
成績評価：毎回の演習　５０％、期末試験　５０％
第3回　指数関数 / 授業内容：指数法則とグラフ / 事前学修：第2回の復習（1時間）
```

`syllabus.md` には次のように写します（文言はそのまま、形だけ整える）：

```markdown
# 達成目標

- 関数の性質を理解する。
- 基本的な微分の計算をする。

（上記は公式シラバス（2026-04-01 取得）の「授業の到達目標」を採録したもの。）

# 授業計画

## 第03回: 指数関数
- 授業内容: 指数法則とグラフ
- 事前学修: 第2回の復習（1時間）

# 評価方法

- 毎回の演習: 50%
- 期末試験: 50%

（上記は公式シラバス（2026-04-01 取得）の「成績評価」を採録したもの。）
```

## 4. 書かないこと

- **学生個人の情報**（氏名・学籍番号・成績・配慮の具体的な内容）は書きません。
- パスワード・共有リンクなど、外に出してはいけない情報は書きません。
- 授業後の記録（出席者数、正答率など）は `syllabus.md` に追記せず、別のメモにします。

## 5. チェックリスト

- [ ] front matter の必須6項目がある
- [ ] コース概要・達成目標に、公式シラバスからの採録と出典がある（公式シラバスがある場合）
- [ ] 授業計画に `total_lessons` と同じ数の `## 第NN回:` がある
- [ ] 評価方法の配点の合計が 100% になる
- [ ] 教材の作り方の `## 毎回作る教材` が、教材の種類の名前で書かれている
- [ ] 学生個人の情報が入っていない
