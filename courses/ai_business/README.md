# AIビジネス入門（サンプル）

全学部・全学年向けの「AIビジネス入門」（全14回・1回100分）から、**AI の技術を扱う2回分**を抜き出したサンプル教材です。
技術的な予備知識を前提にせず、**数式を使わずに**「AI はどう動くのか」を説明します。

各回に「その回のテーマ × 生成 AI」の視点を1つ入れる構成です（第09回：ハルシネーションと RAG／第10回：生成 AI は内挿マシンか）。

## 各回の教材

| ファイル | 内容 |
|---|---|
| `slides.tex` / `handout.tex` | 投影用スライド（付録：用語・出典つき）／配布用（A4横に4枚） |
| `lecture_script.md` | 講義台本（話す内容の骨子・時間配分・言い回しの注意） |
| `amc/exercise.tex` | 選択式の確認問題（5問） |
| `../aib-common.tex.inc` | 2回で共通の色とスライドの型 |

スライドの「考えてみよう」は、受講者に1〜3分で書いてもらう問いです（紙・LMS・チャットなど、手段は問いません）。

## 出典と事実の扱い

- 事例・数値には、スライドの該当ページと付録に出典を書いています。報道・発表元の説明によるもの（例：Google の公表値）はその旨を明記しています。
- 年号・件数は、授業で覚えさせることを目的にしていません。使う前に、最新の情報で確かめてください。
- 図はすべて TikZ で描いたものです。外部の画像・図版は使っていません。
