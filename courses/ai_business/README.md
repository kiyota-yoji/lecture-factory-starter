# AIビジネス入門（サンプル）

全学部・全学年向けの「AIビジネス入門」（全14回・1回100分）から、**3回分**を抜き出したサンプル教材です。第08回はケーススタディのまとめ、第09・10回は AI の技術を扱う回です。
技術的な予備知識を前提にせず、**数式を使わずに**「AI はどう動くのか」を説明します。

科目全体の目標・各回のテーマ・実施要件・教材の作り方は [syllabus.md](syllabus.md) を見てください。

## 各回の教材

| ファイル | 内容 |
|---|---|
| `lesson_plan.md` | 授業計画（到達目標・授業の流れ・教材の設計） |
| `slides.tex` / `handout.tex` | 投影用スライド（付録：用語・出典つき）／配布用（A4横に4枚） |
| `lecture_script.md` | 講義台本（話す内容の骨子・時間配分・言い回しの注意） |
| `amc/exercise.tex` | 選択式の確認問題（5問） |
| `../aib-common.tex.inc` | 各回で共通の色とスライドの型 |

## 第08回：既存の資料から作り直した例

第08回は、Google スライドで作っていた既存の資料（PDF）を、このリポジトリの形に作り直した例です（手順は [docs/SOURCE_MATERIALS.md](../../docs/SOURCE_MATERIALS.md) とスキル `existing-materials`）。

| ファイル | 内容 |
|---|---|
| `08/source/aib08_public.pdf` | 元の資料の写し（ロゴ・画面写真・出どころを確かめられない図を消したもの。原本は Git の外） |
| `08/source/SOURCES.md` | 元の資料の点検の記録（ページごとの第三者の素材・事実の確認・直したこと） |
| `08/lesson_plan.md` | 書き起こしの授業計画。`# 元資料との対応` に原本のページとスライドの対応 |

原本には講義台本がなかったため、第08回の `lecture_script.md` は作り直したスライドに合わせて新しく書いたものです。

スライドの「考えてみよう」は、受講者に1〜3分で書いてもらう問いです（紙・LMS・チャットなど、手段は問いません）。

## 出典と事実の扱い

- 事例・数値には、スライドの該当ページと付録に出典を書いています。報道・発表元の説明によるもの（例：Google の公表値）はその旨を明記しています。
- 年号・件数は、授業で覚えさせることを目的にしていません。使う前に、最新の情報で確かめてください。
- 図はすべて TikZ で描いたものです。外部の画像・図版は使っていません。
