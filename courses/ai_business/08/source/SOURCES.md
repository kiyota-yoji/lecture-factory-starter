## 公開用の写しの作り方

リポジトリのルートで実行（Python と PyMuPDF が必要。消す理由ごとにラベルを変えるため3回に分けた）。

```bash
python3 tools/redact_pdf.py courses/ai_business/08/source/original/aib08_original.pdf step1.pdf --images 8,9,10,12,18 --label "ロゴを削除"
```

```bash
python3 tools/redact_pdf.py step1.pdf step2.pdf --images 16 --label "出どころを確かめられない図のため削除"
```

```bash
python3 tools/redact_pdf.py step2.pdf courses/ai_business/08/source/aib08_public.pdf --images 26 --label "分析ツールの画面写真を削除" --title "AIビジネス入門 #08 AIプラットフォームビジネスの全体像と課題（公開用）"
```

確かめたこと：`pdfimages -list` で画像が 0 個、`pdftoppm -r 60` で 8・12・16・18・26 ページを見て、見出しの文字が残り画像だけが消えていること、`pdfinfo` で作成者などの文書情報が消えていること。文字（締切の日付など）は原本の記録として残している。
