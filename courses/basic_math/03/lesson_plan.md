# 授業概要

「同じ倍率でくり返し増える（減る）量」を表す道具として、指数を正の整数から 0・負の整数・有理数・実数へと広げる。広げるときの決まりは「指数法則がそのまま成り立つように決める」の1つだけであることを押さえ、指数法則を使った計算ができるようにする。そのうえで指数関数 $y = a^x$ のグラフと性質を読み取り、工学での例として複利と減衰（半減期）につなげる。

## 発展目標

# 主要概念

- 指数法則（$a > 0$、$m, n$ は実数）
  - $a^m a^n = a^{m+n}$、$\dfrac{a^m}{a^n} = a^{m-n}$、$(a^m)^n = a^{mn}$、$(ab)^n = a^n b^n$
- 0 と負の指数：$a^0 = 1$、$a^{-n} = \dfrac{1}{a^n}$
- 累乗根と有理数の指数：$a^{\frac{1}{n}} = \sqrt[n]{a}$、$a^{\frac{m}{n}} = \sqrt[n]{a^m} = \left(\sqrt[n]{a}\right)^m$
- 実数の指数：$2^{\sqrt{2}}$ は $2^{1.4}, 2^{1.41}, 2^{1.414}, \dots$ が近づいていく値
- 指数関数 $y = a^x$（$a > 0$、$a \neq 1$）：点 $(0, 1)$ を通る、値は常に正、$x$ 軸が漸近線、$a > 1$ で増加・$0 < a < 1$ で減少
- 底をそろえた大小比較：$a > 1$ のとき $p < q \iff a^p < a^q$
- 応用：複利 $P(1 + r)^n$、半減期 $T$ の減衰 $m_0 \left(\dfrac{1}{2}\right)^{t/T}$

# 強調したいポイント

- 指数を広げるときの決まりは1つだけ：「指数法則がそのまま成り立つように決める」
- $a^0 = 1$、$a^{-n} = \dfrac{1}{a^n}$、$a^{\frac{m}{n}} = \sqrt[n]{a^m}$
- $y = a^x$ はいつも点 $(0, 1)$ を通り、値は正。$a > 1$ なら増加、$0 < a < 1$ なら減少

# つまずきやすい点

- $a^m a^n$ を $a^{mn}$ とする（指数の足し算と掛け算の混同）、$2^3 \cdot 2^4 = 4^7$ のように底まで掛ける
- $2^{-2}$ を $-4$ や $-\dfrac{1}{4}$ とする（負の指数を「負の数」と誤解）
- $a^0 = 0$ とする
- $8^{\frac{2}{3}}$ で分母（累乗根）だけ、または分子（累乗）だけを使う（$2$ や $64$ とする）、$8 \times \dfrac{2}{3}$ と掛け算する
- 指数関数のグラフが原点を通る、$x$ 軸と交わる（$y$ が負になる）と思う
- 半減期の問題で「一定量ずつ減る」（直線的な減少）と考える、半分にする回数を数え違える
