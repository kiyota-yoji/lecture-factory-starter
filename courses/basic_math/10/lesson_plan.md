# 授業概要

向きと大きさをもつ量としてベクトルを導入し、和・差・スカラー倍を矢印の図と成分の両方で計算できるようにする。「寄り道」と「基準点」による式の変形を道具として持たせ、内分点・重心の公式につなげる。工学の例として、力の合成をベクトルの和として扱う。内積・外積は扱わない。

# 主要概念

- スカラーとベクトル、$\overrightarrow{\mathrm{AB}}$・$\vec{a}$、大きさ $|\vec{a}|$
- 等しいベクトル（平行移動しても同じ）
- 和（矢印をつなぐ・平行四辺形）、$\vec{a} + \vec{b} = \vec{b} + \vec{a}$
- スカラー倍 $k\vec{a}$、逆ベクトル $-\vec{a}$、差 $\vec{a} - \vec{b} = \vec{a} + (-\vec{b})$
- 成分：$\vec{a} + \vec{b} = (a_1 + b_1,\ a_2 + b_2)$、$k\vec{a} = (ka_1,\ ka_2)$、$|\vec{a}| = \sqrt{a_1^2 + a_2^2}$
- 寄り道 $\overrightarrow{\mathrm{AB}} = \overrightarrow{\mathrm{AP}} + \overrightarrow{\mathrm{PB}}$、基準点 $\overrightarrow{\mathrm{AB}} = \overrightarrow{\mathrm{OB}} - \overrightarrow{\mathrm{OA}}$
- 内分点 $\vec{p} = \dfrac{n\vec{a} + m\vec{b}}{m + n}$、中点 $\dfrac{\vec{a} + \vec{b}}{2}$、重心 $\vec{g} = \dfrac{\vec{a} + \vec{b} + \vec{c}}{3}$

# 強調したいポイント

- ベクトル＝向きと大きさ。平行移動しても同じもの
- 成分で計算するときは「成分ごとに」足す・かける。大きさは $\sqrt{a_1^2 + a_2^2}$
- 寄り道（つなぐ）と基準点（終点 − 始点）で、ベクトルの式は変形できる

# つまずきやすい点

- 差・スカラー倍で、片方の成分だけ符号を変える（$2\vec{a} - \vec{b}$ を $(5,\ 0)$ とする）、引くところを足す（$(7,\ 0)$）
- 大きさを成分の和・差にする（$(5,\ 12)$ の大きさを $17$・$7$）、平方根を取り忘れる（$169$）
- $\overrightarrow{\mathrm{AB}}$ を「始点 − 終点」で計算する、向きを逆にする（$\overrightarrow{\mathrm{AB}} + \overrightarrow{\mathrm{BC}} = \overrightarrow{\mathrm{CA}}$）
- 中点で2で割り忘れる（$(10,\ 6)$）、差を2で割る（$(3,\ 3)$）
- 内分点の公式で $m$ と $n$ をかける相手を取り違える

# スライド設計

- 枚数：12枚（`slides.tex` の frame 数。`\section` は ベクトルとは／和・差・スカラー倍／式の変形／内分点と重心／工学では）
- 各スライドの1行メッセージ（`slides.tex` の順。`\lfsmessage` があるものはその文言、ないものはフレームの題）：
  1. 表紙（ベクトルの基礎）
  2. 今日のねらい：ベクトル ＝ 向きと大きさをもつ量
  3. スカラーとベクトル：スカラーは大きさだけ、ベクトルは向きと大きさ（矢印 $\overrightarrow{\mathrm{AB}}$、大きさ $|\vec{a}|$）
  4. 等しいベクトル：向きと大きさが同じなら、場所が違っても同じベクトル
  5. 和：矢印をつなぐ（平行四辺形の対角線と同じ、$\vec{a} + \vec{b} = \vec{b} + \vec{a}$）
  6. スカラー倍と差：$k\vec{a}$ は長さ $|k|$ 倍、差は逆向きを足す
  7. 成分で計算する：成分ごとに足す・かける（例：$\vec{a} = (3,\ 4)$、$\vec{b} = (1,\ -2)$ で $\vec{a} + \vec{b} = (4,\ 2)$、$2\vec{a} - \vec{b} = (5,\ 10)$、$|\vec{a}| = 5$）
  8. 寄り道と基準点：$\overrightarrow{\mathrm{AB}} = \overrightarrow{\mathrm{AP}} + \overrightarrow{\mathrm{PB}}$、$\overrightarrow{\mathrm{AB}} = \overrightarrow{\mathrm{OB}} - \overrightarrow{\mathrm{OA}}$（「終点 − 始点」）
  9. 内分点：$\vec{p} = \dfrac{n\vec{a} + m\vec{b}}{m + n}$、中点は $\dfrac{\vec{a} + \vec{b}}{2}$
  10. 重心：三角形の重心 ＝ 3つの頂点の平均（例：A$(0,\ 0)$、B$(6,\ 0)$、C$(3,\ 6)$ → $(3,\ 2)$）
  11. 工学では：力の合成 ＝ ベクトルの和（$(3,\ 0) + (0,\ 4) = (3,\ 4)$、大きさ $5$ N）
  12. まとめ・次回予告（次回：行列の基礎）
