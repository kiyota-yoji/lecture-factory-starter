# 授業概要

関数を「入力に対して出力が1つに決まるもの」として確かめたうえで、角度を弧の長さで測る弧度法を導入する。単位円上を回る点の座標として $\sin$・$\cos$ を定義し、$\tan$、よく使う値、$\sin^2\theta + \cos^2\theta = 1$ と周期性を扱う。最後にグラフから振幅と周期を読み取り、交流電圧・ロボットの腕という工学の例につなげる。

# 主要概念

- 関数 $y = f(x)$、変数
- 弧度法：半径 $1$ の円で弧の長さが $\theta$ になる角を $\theta$ ラジアン、$180^\circ = \pi$
- 単位円上の点 $\mathrm{P}(\cos\theta,\ \sin\theta)$、$\tan\theta = \dfrac{\sin\theta}{\cos\theta}$
- $\sin^2\theta + \cos^2\theta = 1$
- 周期性 $\sin(\theta + 2\pi) = \sin\theta$、$\cos(\theta + 2\pi) = \cos\theta$
- $y = A\sin\omega x$：振幅 $A$、周期 $\dfrac{2\pi}{\omega}$

# 強調したいポイント

- 三角関数＝単位円をまわる点の座標（$x$ 座標が $\cos$、$y$ 座標が $\sin$）
- 弧度法は $180^\circ = \pi$ の1本で変換できる
- $\sin$・$\cos$ は $2\pi$ ごとにくり返す。$y = A\sin\omega x$ なら振幅 $A$、周期 $\dfrac{2\pi}{\omega}$

# つまずきやすい点

- 度と弧度の対応を取り違える（$60^\circ$ を $\dfrac{\pi}{6}$、$120^\circ$ と $\dfrac{2}{3}\pi$ の混同）
- $\sin\dfrac{\pi}{6}$ と $\cos\dfrac{\pi}{6}$（$\dfrac{1}{2}$ と $\dfrac{\sqrt{3}}{2}$）を入れ替える
- $\dfrac{\pi}{2}$ を超える角で符号を落とす（$\cos\dfrac{2}{3}\pi = \dfrac{1}{2}$、$\cos\pi = 1$ とする）
- $\sin^2\theta + \cos^2\theta = 1$ で平方根を取り忘れる・$1 - \sin\theta$ とする（$\cos\theta = \dfrac{1}{5}$）、$\tan$ と $\cos$ を混同する
- 周期を $\omega$ をかけて求める（$y = \sin 2x$ の周期を $4\pi$）、$\omega$ を無視する（$2\pi$）
