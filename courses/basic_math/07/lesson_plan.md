# 授業概要

平均変化率から出発し、区間を縮めた極限として微分係数を定義する。定義どおりの計算で $(x^2)' = 2x$ を確かめたうえで、べき関数の微分の公式を使えるようにし、接線の方程式と「位置を微分すると速度」という工学での意味につなげる。

# 主要概念

- 平均変化率 $\dfrac{f(b) - f(a)}{b - a}$（割線の傾き）
- 微分係数 $f'(a) = \displaystyle\lim_{h \to 0} \frac{f(a+h) - f(a)}{h}$（接線の傾き）
- 導関数 $f'(x)$、記法 $y'$・$\dfrac{dy}{dx}$
- 公式 $(x^n)' = n x^{n-1}$、$(c)' = 0$、定数倍と和の微分
- 接線 $y - f(a) = f'(a)(x - a)$
- （参考）$(\sin x)' = \cos x$、$(\cos x)' = -\sin x$

# 強調したいポイント

- 微分＝その瞬間の「変化の速さ」＝接線の傾き
- 公式は「係数はそのまま、$x^n \to n x^{n-1}$、項ごとに」

# つまずきやすい点

- 平均変化率で分母の $b - a$ を忘れる（$f(b) - f(a)$ だけ答える）
- $(x^3)' = x^2$（係数 $n$ の掛け忘れ）、$3x^3$（指数を下げ忘れ）
- 定数項の微分を 0 にし忘れる、$2x^2$ の微分を $2x$ とする
- 接線で、傾きだけ求めて点を通る条件を使い忘れる（$y = 4x$ とする）
